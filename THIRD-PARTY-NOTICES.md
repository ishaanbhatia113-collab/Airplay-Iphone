version 3**. MirrorDeck runs it unmodified as a separate program. The commit it is built from is
pinned in `engine/build-engine.sh` and recorded in `ENGINE-SOURCE.txt` next to the binary; that commit
is the complete corresponding source of the engine executable.

## 3. Libraries bundled with the engine (from MSYS2)

The engine is linked against, and shipped with, libraries from the MSYS2 distribution
(https://packages.msys2.org, where the build recipe and source of every package can be found).
The main ones:

| Component | Licence | Role |
|---|---|---|
| GStreamer core, gst-plugins-base, gst-plugins-good, gst-plugins-bad | LGPL-2.1-or-later | media pipeline, Direct3D 11/12 output and hardware decoding, WASAPI audio |
| gst-libav | LGPL-2.1-or-later | GStreamer wrapper around FFmpeg |
| FFmpeg | LGPL-2.1-or-later upstream; **GPL as configured by MSYS2** at the time of writing (`PACKAGES.txt` shows the licence of the build you ship) | software H.264/HEVC decoding, AAC-ELD and ALAC audio decoding |
| GLib, libffi, PCRE2, gettext/libintl, libiconv, zlib and similar | LGPL-2.1-or-later, MIT, BSD-3-Clause, zlib | GStreamer's foundations |
| OpenSSL 3 | Apache-2.0 | cryptography for the AirPlay session |
| libplist | LGPL-2.1-or-later | Apple property-list parsing |
| GCC runtime libraries (libgcc, libstdc++, winpthreads) | GPL-3.0 with the GCC Runtime Library Exception; MIT/BSD | compiler runtime |

FFmpeg and some GStreamer plugins pull in further codec libraries. The list above is therefore not
exhaustive; `PACKAGES.txt` in an engine bundle is, and it is generated from the files that were
actually copied.

All of these licences are compatible with distributing the combination under GPL-3.0, which is how a
build that includes the engine has to be distributed: with this notice, the licence texts, and access
to the source code (this repository, the pinned UxPlay commit, and the MSYS2 package sources).

Some of the bundled decoders implement formats (H.264, HEVC, AAC) that are covered by patents in some
jurisdictions. The software licences above do not grant patent rights.
